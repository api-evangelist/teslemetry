Teslemetry provides a proxy to the Tesla Fleet API, enabling DIY automation and integration with Home Assistant, Powerwall, Solar, and other Tesla energy products. It offers real‑time telemetry, webhooks, and server‑sent events for vehicle and energy data, supporting platforms such as Home Assistant, Homey, Homebridge, Node‑RED, and n8n.

**Areas:** Company · Tesla · Fleet API · Home Automation · Energy

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Teslemetry: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
